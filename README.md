Bank Account System

A simple Java-based bank account management system developed to demonstrate core Object-Oriented Programming (OOP) concepts.

Concepts Demonstrated
Encapsulation
Inheritance
Method Overriding
Runtime Polymorphism
Getters and Setters
Account Types
SavingsAccount — includes interest rate
CurrentAccount — includes overdraft limit
StudentAccount — includes its own charge calculation
Technologies
Java
Object-Oriented Programming
Purpose

This project was developed as part of a Java OOP lab to practice implementing classes, inheritance, encapsulation, and polymorphism.
